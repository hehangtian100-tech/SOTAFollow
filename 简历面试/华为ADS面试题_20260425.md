## 一、强化学习方向（深度追问版）

### Q1: Flow-GRPO 如何解决 Diffusion Model 无法直接适配 RL 的问题？

**候选人简历亮点**：落地基于 Flow GRPO 的全链路强化学习方案

**参考答案**：
- **问题根因**：Diffusion Model (Flow Matching) 使用 ODE 路径 $\mathbf{x}_t = (1-t)\mathbf{x}_0 + t\mathbf{x}_1$，是确定性的，无法直接计算 importance sampling ratio $r_t(\theta)$
- **解决思路**：Flow-GRPO 通过 SDE 转换引入随机性，从而支持 RL 的 IS 估计
- **核心创新**：GMFlow/Flow-GRPO SDE Solver 在 ODE 训练基础上成功构建概率密度函数

**追问 1.1**：Flow Matching 的损失函数是什么？为什么它天然适合做回归而非生成？
- **答**：$\mathcal{L} = \mathbb{E}_t \| \mathbf{v}_\theta(\mathbf{x}_t, t) - \mathbf{v} \|^2$，预测向量场而非噪声

**追问 1.2**：GMFlow 和标准 Flow Matching 的区别是什么？
- **答**：GMFlow 在连续时间维度上引入随机性，构造 Wiener 过程支持的 SDE

**追问 1.3**：GRPO 的 group-relative 优势估计和 GAE 的区别是什么？
- **答**：GAE 用 value function 做 baseline，GRPO 用同 group 内样本的均值/标准差做相对比较

### Q2: GSPO 和路由重放（Routing Replay）机制解决 MoE 训练震荡的原理？

**候选人简历亮点**：创新性引入 GSPO 与路由重放机制，大幅增强模型训练稳定性与收敛质量

**参考答案**：
- **问题**：MoE 中 Policy New 与 Policy Old 的专家选择（Routing）不一致导致训练震荡
- **GSPO**：在策略更新时锁定路由选择，缓解分布偏移
- **路由重放**：在训练过程中保留并重用历史路由决策
- **本质**：这是 on-policy 和 off-policy 的权衡问题

**追问 2.1**：MoE 的 Top-K 路由机制在 RL 训练中为什么会导致问题？
- **答**：Top-K 路由具有高度动态性，Policy 更新后专家选择分布会剧烈变化

**追问 2.2**：GSPO 的完整名称是什么？它和 PPO 的数学形式有什么不同？
- **答**：Generalized Skill Policy Optimization [待验证]；核心差异在于加入了路由一致性约束

**追问 2.3**：Routing Replay 如何平衡"探索新路由"和"利用已有稳定路由"？
- **答**：维护历史路由的优先回放队列，以一定概率回放而非每次重新计算路由

### Q3: GT Guidance 有偏采样方案的具体设计？为何 3 倍提升收敛速度？

**候选人简历亮点**：GT Guidance 有偏采样方案使训练迭代由 30k 降至 10k

**参考答案**：

- **GT Guidance**：显式引导模型探索高价值轨迹，优先采样接近 GT 的轨迹

**追问 3.1**：GT Guidance 和 DAgger 有什么区别？

**追问 3.2**：如何避免 GT Guidance 导致过早收敛到局部最优？
- **答**：设计 epsilon-greedy 机制，以一定概率进行随机探索

**追问 3.3**：GT Guidance 的 reward 是如何设计的？
- **答**：与 GT 轨迹的相似度作为额外奖励项，引导模型学习接近专家行为

### Q4: 分项 Adv+Gradnorm 多目标优化 + Temp-Flow 机制的设计？

**候选人简历亮点**：分项 Adv+Gradnorm 实现多目标联合优化，Temp-Flow 弥补奖励稀疏

**参考答案**：
- **分项 Adv**：不同维度的优势函数分开计算（如碰撞、时距）
- **Gradnorm**：平衡不同任务头的梯度更新，解决多 Reward 博弈失衡
- **Temp-Flow**：预测未来奖励来增强当前稀疏奖励信号
- **量化收益**：Temp-Flow 贡献 70+ 例碰撞减少

**追问 4.1**：Gradnorm 的梯度平衡原理是什么？
- **答**：通过动态调整各任务头的损失权重，使它们的梯度范数在训练过程中保持平衡

**追问 4.2**：Temp-Flow 如何预测未来奖励？
- **答**：利用 Flow Matching 的路径特性，在当前时间步预测未来累积奖励的期望

**追问 4.3**：多目标 RL 中如何避免某个目标被过度优化而牺牲其他目标？
- **答**：使用 Pareto 最优或加权求和 + Gradnorm 平衡；设置各目标的最小阈值约束

### Q5: Replay Memory 机制在 GRPO 中的设计？为什么能提升长尾数据利用率？

**候选人简历亮点**：设计经验回放（Replay Memory）机制，大幅提升长尾高价值数据利用率

**参考答案**：

**追问 5.1**：on-policy 和 off-policy 在 GRPO 框架下分别怎么处理？
- **答**：GRPO 本身是 on-policy 的，需要 importance sampling correction；off-policy 版本需要 IS 修正

**追问 5.2**：PER (Prioritized Experience Replay) 的优先级是如何计算的？
- **答**：基于 TD error 绝对值或 reward 稀疏度

### Q6: 你提到 "Diffusion Flow Matching 方案"，请写出完整的 Flow Matching 损失函数和推理时的 ODE Solver

**参考答案**：
- **损失函数**：
$$\mathcal{L}_{FM} = \mathbb{E}_{t \sim [0,1], \mathbf{x}_0, \mathbf{x}_1} \left\| \mathbf{v}_\theta(\mathbf{x}_t, t) - \mathbf{v} \right\|^2$$

其中 $\mathbf{x}_t = (1-t)\mathbf{x}_0 + t\mathbf{x}_1$（线性插值路径）

- **推理 ODE**：
$$\frac{d\mathbf{x}}{dt} = \mathbf{v}_\theta(\mathbf{x}_t, t)$$

**追问 6.1**：为什么 Flow Matching 的线性路径比 DDPM 的噪声路径更稳定？
- **答**：线性路径在像素空间直接插值，梯度方向更一致

**追问 6.2**：你用的 SDE Solver 具体是什么？和 DDIM 的关系？
- **答**：待确认具体 solver 类型；DDIM 是 ODE-based 的确定性采样

### Q7: RL 训练中 reward shaping 有什么常见陷阱？你如何设计有效的 reward？

**参考答案**：
- **常见陷阱**：
  1. Reward Hacking：模型找到取巧行为
  2. 奖励稀疏导致探索困难
  3. 多目标奖励权重敏感

- **有效设计原则**：
  1. 稀疏奖励用 Temp-Flow 等机制弥补
  2. 多目标用 Gradnorm 平衡
  3. 设置安全约束作为硬约束而非软奖励

**追问 7.1**：你的 reward 中碰撞维度是如何定义的？
- **答**：基于 TTC (Time To Collision) 或距离边界的惩罚项

**追问 7.2**：时距控制的 reward 如何设计？
- **答**：与前车距离与 TTC 的偏差作为惩罚项
