## 日期：20260510

### LLM 领域（FM基础知识）

**主题：VQVAE 视觉 Tokenizer**

1. **[基础概念题]** 为什么 World Model 不能直接在像素空间学习环境动态 $p(s_{t+1}|s_t, a_t)$？VQVAE 作为视觉压缩器在 World Model pipeline 中承担什么角色？
   - **答案/思考提示**：像素空间维度极高（256×256 RGB 图像有 196,608 维），直接在像素空间学习计算不可行，且像素级重建 loss 不利于学习高层语义。VQVAE 的角色：① 将高维图像压缩为低维离散 token（通常 8×8×D，token 数减少 100 倍以上）；② 提供语义更有意义的表示（码本向量是通过重建损失学习到的，倾向于保留对任务重要的视觉特征）；③ 离散 token 便于与语言模型、自回归框架结合。

2. **[深度思考题]** VQVAE 的量化操作 $\arg\min_j \|h_e(x) - e_j\|_2^2$ 本质上不可导，为什么可以用 Straight-Through Estimator (STE) 解决梯度问题？STE 的物理含义是什么？
   - **答案/思考提示**：前向传播：$z_q = \text{quantize}(h_e)$ 产生离散码字；反向传播：STE 将 $z_q$ 的梯度直接复制给 $h_e$，即 $\frac{\partial \mathcal{L}}{\partial h_e} = \frac{\partial \mathcal{L}}{\partial z_q}$。物理含义：前向时"强制"特征向量使用码本向量（硬量化），反向时"假装"量化不存在，梯度透明地流回编码器。这相当于把量化当作一个"信息瓶颈"，强迫编码器学习能被码本近似的表示。

3. **[实践应用题]** 如果你设计一个视频生成的 tokenizer，发现码本利用率只有 30%，大量码字从未被使用，你会如何诊断和解决这个问题？
   - **答案/思考提示**：诊断：① 码本太小或维度太高导致稀疏；② 编码器提取的特征分布与码本不匹配；③ 训练数据多样性不足。解决方向：① 增加码本大小 K（但要平衡压缩率）；② 使用更复杂的码本更新策略（如moving average replaces EMA）；③ 引入类似 VQGAN 的对抗损失改善码字利用；④ 诊断码本崩溃原因——如果是"最速下降"导致所有输入聚集到同一码字，考虑增大 commitment cost 或使用 exponential moving average 更新码本。

4. **[优缺点对比题]** VQVAE 与 VAE/β-VAE 都学习隐表示，但 VAE 的隐空间是连续的而 VQVAE 是离散的。这种离散化设计在 World Model 中有什么独特优势？
   - **答案/思考提示**：离散优势：① 与语言模型自回归框架天然契合（语言本身就是离散 token）；② 离散表示的组合性（有限码字通过不同组合表达无限场景），类似词向量的"组合性"；③ 降低了对表示精度的要求——World Model 只需预测"下一个码字"而非"下一个像素"，任务更简单；④ 离散表示更易压缩存储，跨任务迁移时表示更紧凑。连续表示优势：表示更精细，但与离散序列模型结合需要额外量化步骤。

5. **[深度思考题]** 为什么 VQVAE 的码本大小 K 和码字维度 D 是两个关键超参数？它们分别影响什么特性？如果要压缩率更高，应该优先调整哪个参数？
   - **答案/思考提示**：K 影响表示的容量（能区分多少种不同的视觉模式），D 影响每个码字的表达能力（能编码多细粒度的信息）。高压缩率场景：通常降低空间分辨率（如从 16×16 降到 8×8）比增大 K 更有效，因为压缩主要来自空间维度的下采样。K 的选择需要平衡：太小导致码本冲突（不同内容映射到同一码字），太大训练不充分（大量码字未被使用）。实际中常用 K=8192~65536，D=256~512 的配置。
