## 日期：20260514

### LLM 领域
**通用领域思考题**

1. [基础概念题] FlashAttention 通过 IO-aware 的分块计算和重新计算技术，显著提升了注意力的计算效率。请从 HBM 带宽和 SRAM 带宽的角度解释：为什么减少 HBM 访问次数比优化计算本身更重要？
   - 答案/思考提示：A100 GPU 的 HBM 带宽约 1.5 TB/s，SRAM 带宽约 19 TB/s，差距约 10-15 倍。更关键的是，HBM 访问延迟约 100ns 而 SRAM 约 1ns，差距 100 倍。注意力计算本身（矩阵乘法、softmax）是 compute-bound 而非 memory-bound，但标准实现需要反复从 HBM 读写 N×N 的中间矩阵。FlashAttention 通过让计算在 SRAM 内完成，大幅减少数据移动，其收益远大于优化计算本身。

2. [深度思考题] FlashAttention 在反向传播时采用"重新计算"（recomputation）策略而不是存储前向中间结果。这看似是"浪费"了计算资源，但实际却加速了整体训练。为什么重新计算反而更快？
   - 答案/思考提示：存储中间结果需要写入 HBM 并在反向时读回，这是 O(N²) 的内存访问开销。重新计算只需要将 Q、K、V 分块加载到 SRAM，在片上完成计算，无需存储 QK^T 等中间矩阵。当 N 很大时，HBM 访问的时间成本远大于重新计算的计算成本（矩阵乘法在 SRAM 上极快）。这是一种经典的"用计算换内存"优化。

3. [实践应用题] 假设你需要将 FlashAttention 部署到一个 SRAM 非常小（如 10KB）的嵌入式设备上，但序列长度需要支持到 16K。你需要如何调整分块策略？
   - 答案/思考提示：SRAM 大小决定了单次能容纳的块尺寸。当 SRAM 受限时，需要：① 减小 Q 的分块大小 Tc 和 K/V 的分块大小 Tr，但过小会导致分块数量激增，增加外层循环开销；② 考虑分级策略——先在片上计算局部注意力，再将结果压缩后与全局信息融合；③ 对于极端受限场景，可能需要近似方法（如 FlashAttention-2 的序列并行）或多级 tiling。

4. [优缺点对比题] FlashAttention 与稀疏注意力（如 Longformer、BigBird）相比，在精度、效率和适用场景上有什么本质区别？
   - 答案/思考提示：FlashAttention 是精确注意力（数学等价于标准注意力），无精度损失，通过 IO 优化提升效率；稀疏注意力是近似方法，通过丢弃部分注意力连接（如局部窗口、全局 token、随机 token）降低复杂度，有理论精度损失但实际应用中通常可接受。FlashAttention 适合需要精确结果且有一定算力预算的场景；稀疏注意力适合超长序列（百万级）且对精度要求不苛刻的场景。

5. [基础概念题] 在 Transformer 的注意力机制中，softmax 的数值稳定性是一个重要问题（当输入值很大时，exp 可能溢出）。FlashAttention 使用什么技术来解决这个问题？其数学原理是什么？
   - 答案/思考提示：FlashAttention 使用在线 softmax（online softmax）技术，也称为"安全 softmax"或"数值稳定的分块 softmax"。核心思想：计算 softmax 时先找最大值 m = max_i x_i，用 exp(x_i - m) 代替 exp(x_i)，由于 exp(x_i - m) ≤ 1，不会溢出。分块计算时需要额外维护 max 值和归一化因子的统计量，确保最终结果数学等价于完整 softmax。FlashAttention 在前向和反向都使用了这一技巧。
