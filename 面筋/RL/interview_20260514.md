### RL 领域
**通用领域思考题**

1. [基础概念题] PPO 算法使用 clipped surrogate objective 的核心目的是什么？当概率比 r_t(theta) 超出 [1-epsilon, 1+epsilon] 区间时，梯度会如何变化？
   - 答案/思考提示：Clipped objective 将策略更新的幅度限制在信任域内。当 r_t(theta) 被 clip 后，即使该动作非常好（r_t 很大）或非常差（r_t 很小），目标函数也不再给予更大的优化信号。这避免了灾难性策略退化，同时允许在信任域内充分学习。PPO 的 KL 约束是软约束而非硬约束，通过目标函数的变化而非惩罚项来实现。

2. [深度思考题] 强化学习中的 "deadly triad" 包括函数近似、自举法和离策略学习。为什么这三者同时存在会导致训练不稳定甚至发散？能否举出一个同时满足三者但依然稳定的算法？
   - 答案/思考提示：函数近似引入估计误差，自举法将误差传播到未来时间步，离策略数据分布偏移放大误差。DDPG 虽然三者都有（因为使用函数近似和自举，且常用离策略 buffer），但通过确定性策略和 target network 的软更新降低了发散风险。TD3 则通过双重 Q 网络和延迟策略更新进一步稳定。

3. [实践应用题] 你在训练一个 RL 策略时发现：整体 reward 曲线在上升，但某几个特定状态下的失败率始终很高，且这些状态在训练数据中出现的频率较低。请设计一套诊断和解决流程。
   - 答案/思考提示：① 使用 reward decomposition 分析各状态的贡献；② 通过状态访存频率（state visitation）分析找到"状态空洞"；③ 优先经验回放（PER）增加稀缺状态样本权重；④ HER（Hindsight Experience Replay）重标记失败轨迹的目标；⑤ 针对稀缺状态设计 curriculum learning，渐进引入困难状态。

4. [优缺点对比题] 相比 TRPO 使用 KL 散度作为硬约束，PPO 将约束目标化处理（通过 clip）有什么优势和劣势？什么场景下你会选择 TRPO 而非 PPO？
   - 答案/思考提示：PPO 优势：实现简单（单阶段优化）、计算效率高、内存占用低、训练更稳定。PPO 劣势：超参数 epsilon 的选择敏感度较高、理论保证弱于 TRPO。选择 TRPO 的场景：① 需要严格信任域约束的安全关键应用；② 需要更坚实的理论基础背书；③ 连续动作空间大且策略变化剧烈时。

5. [基础概念题] 在策略梯度方法中，baseline b(s) 的引入为什么能减少方差而不引入偏差？请从数学推导角度说明。
   - 答案/思考提示：由策略梯度定理 ∇_θ J = E[∇_θ log π(a|s) · A(s,a)]，其中 A = Q - V。任何关于状态 s 的函数 b(s) 满足 E[∇_θ log π(a|s) · b(s)] = 0（因为 E[a~π] ∇_θ log π(a|s) = 0），因此从 Q-V 替换为 Q-b 不会改变期望，即无偏。b(s) 通常取 V(s)，取最优 baseline 可最小化方差。
