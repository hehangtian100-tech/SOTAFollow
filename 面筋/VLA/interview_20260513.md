## 日期：20260513

### VLA 领域
**通用领域思考题**

1. [基础概念题] Vision-Language-Action (VLA) 模型与传统视觉语言模型的本质区别是什么？为什么不能简单地将 VLM 的输出 token 映射为动作？
   - 答案/思考提示：VLA 需要处理时序决策和低层次动作空间。传统 VLM 输出是离散文本 token，而机器人动作通常是连续的高维向量（如 7-DOF 机械臂姿态）。此外，VLA 需要处理视觉反馈闭环：当前动作影响下一帧观察，这要求模型具备时序建模和因果推断能力。

2. [深度思考题] 为什么大多数 VLA 方法采用 diffusion model 或 flow matching 作为动作解码器，而不是回归型方法（如 MSE loss）？
   - 答案/思考提示：动作空间具有多模态特性：同一个目标状态可能对应多种合理的动作序列。Diffusion model 能够建模这种多模态分布，而 MSE 回归只能输出单模态均值。此外，diffusion 的迭代去噪过程提供了动作平滑性约束，适合机器人控制的物理连贯性要求。

3. [实践应用题] 假设你要将一个桌面机器人 VLA 模型迁移到户外物流机器人，会遇到哪些主要挑战？如何用现有技术缓解这些问题？
   - 答案/思考提示：主要挑战包括：① 光照/天气变化导致视觉泛化问题；② 动作频率和精度要求不同；③ 动态障碍物和行人。缓解方法：使用域随机化（domain randomization）、使用视觉编码器（ 如 SigLIP、CLIP）的鲁棒特征、结合雷达/深度传感器的多模态融合、运动重定位（retargeting）来适配不同机器人 kinematics。

4. [优缺点对比题] RT-2 采用了 vision-language model fine-tuning 的方式，而 π0 采用了 foundation model + learned action decoder 的方式。这两种架构各有什么优缺点？
   - 答案/思考提示：RT-2 方式端到端训练，视觉-语言-动作联合优化，但需要大量 VLA 训练数据和计算；动作decoder方式解耦了感知和动作学习，foundation model 的预训练知识可以保留，但在两者接口处可能存在信息瓶颈。π0 的方式更适合数据有限的场景，而 RT-2 在数据充足时能更好地挖掘 VL 模型的全部潜力。

5. [基础概念题] 在具身智能中，"闭环控制"（closed-loop）和"开环执行"（open-loop）的区别是什么？为什么当前 VLA 普遍采用闭环方式？
   - 答案/思考提示：开环执行是预规划完整动作序列后一次性执行，不利用执行中的感知反馈；闭环执行是每步根据当前观察重新决策或调整。VLA 采用闭环是因为：机器人任务中环境动态变化（如被抓取物体移动）、视觉模型可能出现误判需要实时修正、长时序任务中误差会累积需要周期性重规划。
