## 日期：20260515

### VLA 领域
**通用领域思考题**

1. [基础概念题] VLA（Vision-Language-Action）模型的核心pipeline通常包含哪些模块？视觉编码器、动作解码器分别承担什么角色？为什么大多数 VLA 采用预训练的 VLM 而非从头训练？
   - 答案/思考提示：典型 VLA pipeline：视觉编码器（提取图像特征）→ 融合模块（视觉-语言对齐）→ 动作解码器（输出机器人动作）。预训练 VLM 已学习丰富的视觉-语言对应关系，理解场景语义、物体关系和空间结构。这些语义知识在机器人数据中稀缺且标注成本高，直接从头训练需要海量机器人数据才能达到类似语义理解。预训练 VLM 提供强有力的初始化，机器人微调只需适配动作空间。

2. [深度思考题] 在 VLA 的动作生成中，扩散模型（Diffusion Model）和自回归模型（Autoregressive Model）各有什么优缺点？为什么 π0.7 选择 Flow Matching 而非传统扩散模型？
   - 答案/思考提示：扩散模型在连续动作空间生成质量高、可建模多模态动作分布，但推理延迟高（需要多步去噪）；自回归模型推理快（一次性输出），但适合离散 token 化动作，精细连续控制能力弱。Flow Matching 是连续正则化流（CNF）的一种，直接学习向量场从噪声到数据的映射，比传统扩散少了一步 noise prediction→data prediction 的转换，训练更稳定，采样速度更快（10-20 步 vs 上百步）。

3. [实践应用题] 你需要在工厂环境中部署 VLA 机器人来执行装配任务，但工厂光照条件多变、零件摆放位置不固定。请从 VLA 系统的角度分析如何提升泛化能力，至少给出 3 个具体的技术方向。
   - 答案/思考提示：① 数据层面：Domain Randomization 在模拟器中随机化光照、纹理、背景、相机参数；② 视觉编码器层面：使用大尺度预训练的视觉编码器（如 Gemma、SigLIP）增强语义泛化；③ 动作层面：使用 Flow Matching 等方法生成多样性动作，而非单一最优动作；④ 策略层面：学习本体无关的技能表征（action chunk）而非特定位置的动作序列；⑤ 任务层面：利用 language instruction 提供任务级别的 zero-shot 泛化。

4. [优缺点对比题] 端到端 VLA（如 RT-2、OpenVLA）与模块化 VLA（如 π0.7 的 Cogntion-Memory-Action 解耦）在系统设计上有什么本质差异？各自的鲁棒性和可扩展性如何？
   - 答案/思考提示：端到端 VLA 简单、联合优化但可解释性差、视觉和语言表征容易冲突；模块化 VLA 解耦感知-记忆-动作，模块可独立迭代、可复用性高，但模块间的 interface 设计很重要。鲁棒性：模块化因各模块专注单一任务通常更鲁棒；可扩展性：端到端随数据增加更容易 scale，模块化需要考虑模块间的 aligned growth。π0.7 的 Cogntion-Memory-Action 解耦让视觉编码器可以独立 scale 而不影响动作专家。

5. [基础概念题] 在 VLA 的训练中，数据异构性（不同机器人本体、数据质量、任务类型混合训练）是一个核心挑战。π0.7 中的 Diverse Context Conditioning（DCC）和 Actuate2025 中的 Geometry-Aware Tokenization 分别是如何解决这个问题的？两者思路有何异同？
   - 答案/思考提示：DCC 通过扩展单一 language instruction 为多模态上下文（language + 策略元数据 + sub-goal 图像）让模型区分不同数据质量/策略属性；Geometry-Aware Tokenization 通过本体几何 token 显式建模不同机器人的几何差异。两者的共同点：都承认数据异构性的存在并加以建模而非简单丢弃低质量数据；不同点：DCC 是在 context 层面加信息，Geometry-Aware 是在表示层面规范化。
